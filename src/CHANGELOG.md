# GW Green changelog

## 34.0 - Initial Pale Moon 34 release

Initial public GW Green release for Pale Moon 34.

Built from the final confirmed Glowy Green Pale Moon port test state, with the public release identity changed to GW Green.

### Release identity

- Renamed public theme to **GW Green** for the final release identity.
- Changed add-on/theme ID to `gw-green@Halvar666`.
- Changed internal skin name from `glowygreen` to `gwgreen`.
- Changed versioning to Pale Moon milestone-based version `34.0`.
- Compatibility range set to Pale Moon `34.0` through `34.*`.

### Compatibility fixes included

- Pale Moon 34 complete theme package cleanup.
- Toolbar fallback icons for modern Pale Moon UI elements.
- History popup and bookmarks popup icons restored.
- PM Stats icon recolored to better match the theme palette.
- Downloads indicator fixed for Pale Moon's modern download panel behavior.
- Stable full-size downloads indicator icon.
- Feed/subscribe icon alignment and jitter fixes.
- Permissions Manager install-themes icon restored.
- Add-ons Manager Languages category icon selector fixed.
- All Tabs panel styled to match the theme.
- Windows menu checkbox/radio alignment fixed while preserving Glowy-style check/radio artwork.
- Windows Quick/App menu geometry fixed for splitmenu and iconic rows.

### Licensing and attribution

- Added GPLv3 license text as `COPYING`.
- Added direct archived AMO license reference for the original Firefox Glowy Green add-on.
- Added explicit credits for glowplug / Greg Broadbent as original author.
- Added explicit maintenance credit for Halvar666.
